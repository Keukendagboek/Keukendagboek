Eerste keer instellen

Om de app te delen met je huishouden, heb je een gratis Firebase-database nodig. Volg de stappen hieronder — duurt ongeveer 5 minuten.

Stap 1 — Maak een gratis Firebase project aan Ga naar console.firebase.google.com, klik op "Add project", geef het een naam (bijv. "Keukendagboek") en maak het aan. Google Analytics mag je uitschakelen.
Stap 2 — Zet een database aan In je project, ga naar Build → Firestore Database → Create database. Kies "Start in test mode" en selecteer een server in Europa (bijv. eur3).
Stap 3 — Haal je app-configuratie op Ga naar Project Settings (tandwiel) → General → Your apps → Web app (</>). Registreer een app en kopieer de config-gegevens hieronder.
Stap 4 — Vul je gegevens in

Je gegevens worden alleen lokaal opgeslagen op dit apparaat.
